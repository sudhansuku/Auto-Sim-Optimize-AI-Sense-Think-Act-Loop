# Auto-Sim-Optimize-AI-Sense-Think-Act-Loop
 an open-source agentic framework designed to automate the design-to-simulation loop for injection molding. By integrating OpenFOAM (openInjMoldSim) with a Python-based Genetic Algorithm (GA), the system functions as a closed-loop "Sense-Think-Act" agent that autonomously optimizes process parameters for complex geometries, such as orthodontic brackets.
